# Antojo

**Busca el plato, no el restaurante.** Antojo compara platos de comida en Tarija, Bolivia: escribes "hamburguesa" y ves las mejores hamburguesas cerca, ordenadas por la calificación del plato y su precio. Los restaurantes publican sus platos gratis, sin comisión por venta.

Proyecto de la materia **Gerencia de las TIC**.

## Contenido del repositorio

| Carpeta | Qué hay |
|---|---|
| [`docs/`](docs/README.md) | Documentación por fases: idea, mercado, Lean Canvas, validación en Tarija, ingeniería de requisitos, desarrollo, escalabilidad y gestión |
| [`mvp/`](mvp/README.md) | El MVP: web/PWA con React, Vite, Tailwind y Supabase |
| `.claude/skills/` | Skills oficiales usadas para el desarrollo (registradas en `skills-lock.json`) |

## Ejecutar el MVP

```bash
cd mvp
npm install
npm run dev
```

Las instrucciones completas (base de datos, claves y demo) están en [`mvp/README.md`](mvp/README.md).
