# Anexo B. Cuestionario a clientes

**Datos generales:** edad, sexo, ocupación.

1. ¿Cuántas veces por semana come fuera o pide comida?
2. Cuando tiene hambre, ¿en qué piensa primero? *(en un plato / en un restaurante / depende)*
3. ¿Cómo decide dónde comer? *(respuesta múltiple: redes sociales / recomendación / app de delivery / Google Maps / costumbre)*
4. ¿Usa apps de delivery? *(PedidosYa / Yango / ambas / ninguna)*
5. ¿Cuánto gasta normalmente por persona en una comida fuera? *(Bs)*
6. ¿Alguna vez pidió un plato malo en un lugar bien calificado o recomendado? *(Sí / No)*
7. *(Se muestran dos maquetas)* ¿Qué calificación le da más confianza? *(por plato / por local / me da igual)*
8. ¿Usaría Antojo para decidir qué y dónde comer? *(Sí / Tal vez / No)*
9. ¿Escribiría reseñas de los platos que prueba? *(Sí / Sí, con incentivo / No)*
10. ¿Pagaría por usar la app? *(Sí / No)*
11. ¿Qué filtro le importa más? *(calificación / precio / distancia / delivery / abierto ahora)*
