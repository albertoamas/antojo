# Anexo A. Cuestionario a restaurantes (dueños o administradores)

**Datos generales:** cargo de quien responde, tipo de negocio, zona, años de funcionamiento.

1. ¿Cómo consigue clientes nuevos? *(respuesta múltiple: redes sociales / boca a boca / PedidosYa / Yango / WhatsApp / letrero / otro)*
2. ¿Trabaja con apps de delivery? ¿Con cuáles? *(PedidosYa / Yango / ninguna)*
3. Si trabaja con apps de delivery, ¿qué tan satisfecho está? *(1 = nada, 5 = muy satisfecho)*
4. ¿Cuánto gasta al mes en publicidad, aproximadamente? *(Bs)*
5. *(Se explica el concepto de Antojo)* ¿Publicaría su menú y sus platos en Antojo si fuera gratis? *(Sí / Tal vez / No)*
6. ¿Pagaría un plan mensual con estadísticas y promociones? *(Sí / Tal vez / No)*
7. ¿Cuánto pagaría como máximo al mes? *(Bs 0 / hasta Bs 50 / Bs 51–100 / Bs 101–150 / más de Bs 150)*
8. ¿Qué le preocupa de una plataforma así? *(abierta)*
9. ¿Qué dato le sería más útil? *(platos buscados en su zona / vistas por plato / clics a "Cómo llegar" o "Pedir" / comparación con la competencia / ninguno)*
